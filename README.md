# Employee Attrition Analysis

An end-to-end employee attrition analysis project using **Python and Tableau** to identify workforce patterns and factors associated with employee turnover.

## 📌 Project Overview

Employee attrition is an important HR analytics problem because understanding why employees leave can help organizations identify workforce trends and areas that may require attention.

This project analyzes employee data to explore attrition patterns across factors such as:

- Overtime
- Job satisfaction
- Job role
- Age group
- Job involvement
- Overall employee attrition

The analysis was performed using Python for data analysis and Tableau for interactive visualization.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Tableau
- Git & GitHub
